# Code of Conduct

Git Extensions Cross Platform is an independent open-source project. While it is currently
solo-maintained, all interactions — whether in issues, pull requests, or discussions — should
be respectful and constructive.

## Expectations

- Be respectful of differing viewpoints and experiences.
- Gracefully accept constructive criticism.
- Focus on what is best for the project.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Trolling or deliberately disruptive behavior.
- Publishing others' private information without consent.

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainer via the GitHub
repository's contact options. The maintainer has the right and responsibility to remove, edit,
or reject contributions that do not align with this code of conduct.
